[1. 학습 현황 관리 페이지 (/admin/learners) — 좌우 분할] 좌측 패널 — 학습자 목록: - 상단: 교과목 드롭다운 + 반 드롭다운
- 미소속 학습자 그룹 + 반별 학습자 그룹
- 검색 필드 (닉네임 검색)
- 개별 학습자 클릭 시 우측에 상세 표시
- 하단: 표시 건수 조절 (10명/20명) 우측 패널 — 반 전체 뷰 (학습자 미선택 시): - 반 이름 표시 (예: "초급 A반 (2명)")
- 지표 카드 4개:
- 총 학습자: 반 소속 학습자 수 + 전주 대비 증감
- 게임 활동률: 최근 1주 내 플레이 비율 + 전주 대비
- 평균 완료율: 16종 게임 평균 클리어율 + 전주 대비
- 평균 점수: 반 평균 게임 점수 + 전주 대비
- 주차별 평균 이수율 막대 차트 (1~15주, 배정 주차/미배정 구분)
- 지도가 필요한 학생 안내 (활동 저조/성적 부진 학습자 자동 감지)
- 미디어별 참여 현황: 도넛 4개 (文 텍스트 / 画 이미지 / 声 음성 / 影 영상)
- 학습 시간대: 도넛 차트 (오전 6-12시 / 오후 12-18시 / 저녁 18-24시 / 밤 0-6시)
- 하단 버튼: [ CSV 다운로드] [ AI 피드백 일괄 생성]
- AI 피드백 일괄 생성 클릭 시: 해당 반 소속 학습자를 순차적으로 처리
- 각 학습자에 대해 Claude API로 루브릭 평가 + 서술형 피드백 자동 생성 → DB 저장
- 진행 상태 표시 (예: "2/5명 생성 중...")
- 완료 후 각 학습자의 피드백 탭에서 결과 확인·수정·전달 가능
[2. 개별 학습자 상세 뷰 (학습자 클릭 시)] 상단: 닉네임 | 소속 교과목(링크) | 소속 반 지표 카드 4개: 플레이(N/16) | 정답률(N%) | 칭호 | 약점(AI 분석) 2개 탭: 학습 현황 | 피드백
(a) 학습 현황 탭: - 주차별 이수율 막대 차트 (5색: 완료 초록/부분 노랑/미완료 빨강/미배정·미래 회색/현재 주차 강조)
- 미디어별 완료도: 도넛 4개 (文/画/声/影 개인 완료율)
- 학습 시간대: 도넛 차트 (개인)
- 자주 틀리는 단어 TOP 10: 오답 빈도 순위 (단어/한자 단위) - 16종 게임별 플레이 현황 표:
- 주차 배정 게임 / 기타 플레이 구분
- 각 게임: 점수 | 클리어 수 | 정답률 (미플레이 시 "—")
- [ CSV 다운로드] 버튼
(b) 피드백 탭: - AI 피드백 영역:
- 미생성 시: [ 피드백 생성] 버튼
- 생성 완료 시: 생성 날짜 + [ 다시 생성] 버튼
- 루브릭 평가 요약 (100점 만점) 표:
- A1 음절 ~ A4 어법 (四维基准, 각 10점)
- B1 듣기 ~ B4 쓰기 (五项技能, 각 10점)

- 각 항목: 점수 + 등급 (최우수/우수/보통/미흡/매우 미흡)
- 종합: 합산 점수
- 서술형 피드백 (Claude API 생성):

- 각 목표에 긴급()/권장() 우선순위 배지

[주의사항]
- 기존 게임 코드, AuthContext는 변경하지 말 것

- 교수자는 자신의 반에 소속된 학습자만 조회 가능 (SECURITY DEFINER 함수)

자료에 관하여

이 페이지는 학위논문 제7장 7.3.3에서 다룬 학습 성과 관리 기능의 개발 기록 가운데, 지면에서 생략한 프롬프트 입력 기록과 개발 과정의 주요 화면을 수록한 것이다. 화면은 개발 당시의 기록이므로 현재의 웹앱과 다를 수 있다.

수록한 프롬프트는 실제 입력 기록이므로 문구를 사후에 고치지 않았다. 다만 인쇄 지면에 맞추어 줄이 나뉜 부분은 화면에서 읽기 쉽도록 다시 이어 붙였다.
