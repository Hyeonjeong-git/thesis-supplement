Lovable 입력 내용
교수자가 15주 커리큘럼을 설계할 수 있는 편집 화면을 구현하고, CSV 업로드와 AI 자동 생성을 모두 지원해줘.
[1. 커리큘럼 목록 페이지 (/admin/curriculum)]
- 상단 2개 버튼: [+ 새로운 커리큘럼 만들기] [🤖 AI 자동 생성]
- 커리큘럼 카드 목록: 교과목명, 설명, 생성일, 연결된 반(초록 배지), [편집] [복제] [삭제] 버튼
[2. 수동 생성 모달 (+ 새로운 커리큘럼 만들기)]
- 커리큘럼 이름 (필수)
- 설명 (선택)
- 연결할 반 (드롭다운: 교수자의 반 목록)
- 템플릿 선택: 기본 15주 학습 과정 / 빈 커리큘럼
[3. 커리큘럼 편집 화면 (/admin/curriculum/:id) — 4개 탭] 상단: 교과목명 + 설명 + [✏ 수정] 버튼 탭 구조: 커리큘럼 구조 | 단어 데이터 | 문장 데이터 | 📄 강의 노트
(a) 커리큘럼 구조 탭: - "시작하기" 안내 카드: 4단계 절차 안내 (①샘플 CSV 다운로드·수정 ②구조 CSV 업로드 ③단어 CSV 업로드 ④문장 CSV 업로드)
- CSV 형식 안내: week(필수), title(필수), description(선택), start_date(선택), end_date(선택)
- [📥 샘플 CSV 다운로드] 버튼
- CSV 드래그&드롭 업로드 영역
- 🤖 AI 게임 일괄 추천 섹션: 안내 문구 + [🤖 AI 게임 일괄 추천] 버튼
(b) 단어 데이터 탭: - "단어 데이터 (CSV-A)" 제목 + "6종 게임에 적용: 사천성·타자 히어로·단어 팡팡·한자 연금술·성조 클라임·분류 달인"
- CSV 형식 안내: week, word(필수), pinyin(선택), meaning_kr(선택)
- 안내: "pinyin·한국어 뜻을 비워두면 기존 어휘 DB에서 자동 매칭하고, DB에 없는 단어는 AI가 보완합니다"
- [📥 샘플 CSV 다운로드] + CSV 업로드 영역
(c) 문장 데이터 탭: - "문장 데이터 (CSV-B)" 제목 + "2종 게임에 적용: 징검다리 점프·버블버블"
- CSV 형식 안내: week, sentence(필수), pinyin(선택), meaning_kr(선택), words(선택)
- [📥 샘플 CSV 다운로드] + CSV 업로드 영역
- [🤖 관련 문장 생성] 버튼 (Claude API, 난이도/길이/어법/개수 제어)
(d) 강의 노트 탭: - "강의 노트 (N/15주 생성됨)" + [일괄 재생성] 버튼
- 15주 리스트: 각 주차에 미생성(⚠)/생성됨 배지 + [🤖 생성] 버튼
[4. AI 커리큘럼 자동 생성 (🤖 AI 자동 생성 클릭 시)] 세팅 폼 모달 10개 항목: - 커리큘럼 이름 (텍스트, 필수)
- 난이도 모드 (라디오: 《等级标准》 급수 기반 / 자유 설정)
- 대상 급수 범위 (드롭다운 2개: 시작~끝 급수, 급수 기반 시 필수, 자유 설정 시 숨김)
- 교재명/학습 주제 (텍스트, 필수)
- 학기 시작일·종료일 (날짜 선택, 필수)
- 주당 단어 수 (숫자 입력, 3~30개, 기본값 10)
- 학습목표 (텍스트 영역, 선택)
- 주당 문장 수 (숫자 입력 3~20개 + "자동(단어 수 기반)" 체크박스)
- 문장 형식 (드롭다운: 단문 / 대화)
- [취소] [🤖 생성 시작] 버튼 생성 흐름: - Step 1: 15주 구조 생성 (제목, 설명, 날짜 자동 계산)
- Step 2: 주차별 단어 생성 (급수 기반→biaozhun_cihui DB 추출, 자유→AI 직접 생성)
- Step 3: 주차별 문장 생성 (단어 기반, 문장 형식 반영)
- Step 4: 게임 배정 (호환성 검증)
- 프로그레스 바 표시
- 완료 후 미리보기 (15주 아코디언) → [✅ 확인 및 저장] → DB 일괄 저장
- AI API: Gemini API — gemini-3.1-flash-lite-preview (Edge Function: generate-curriculum)
- Rate Limit 대응: 프론트엔드에서 1주 차씩 순차 호출 + 2초 딜레이
[5. AI 게임 일괄 추천]
- [🤖 AI 게임 일괄 추천] 클릭 시 15주 전체 단어/문장 데이터 로드
- 주차별 16종 게임 호환성 검증:
- 사천성: 이모지 매칭 가능 어휘 ≥ 4개
- 분류 달인: 2개 이상 카테고리에 분포
- 기타 커스텀 게임: 어휘/문장 수 최소 기준
- 미디어 4종(방탈출, 탐정, 위챗, 팩트체커): 자동 추천 제외
- 주당 3~5개 상한 적용
- 결과 미리보기 → [✅ 적용] → curriculum_weeks.game_keys 일괄 UPDATE
[6. DB 테이블]
- curriculum_weeks: curriculum_id, week_number, title, description, start_date, end_date, game_keys
- curriculum_words: curriculum_id, week, word, pinyin, meaning_kr
- curriculum_sentences: curriculum_id, week, sentence, pinyin, meaning_kr, words
- 모든 테이블에 curriculum_id FK (ON DELETE CASCADE)
- RLS: SELECT 전체 허용, INSERT/UPDATE/DELETE instructor만
[주의사항]
- 기존 게임 코드, AuthContext는 변경하지 말 것
- AuthContext의 onAuthStateChange 콜백은 절대 async로 만들지 말 것
- 기존 RLS 정책은 변경하지 말 것
- Gemini API Key는 Supabase Secrets에 GEMINI_API_KEY로 등록됨
- 8주차(중간), 15주 차(기말)는 복습 주차로 단어/문장 없이 처리

커리큘럼 콘텐츠 보강 구현 프롬프트

Lovable 입력 내용
커리큘럼 콘텐츠를 AI로 보강하고, 강의 노트를 자동 생성하는 기능을 구현해줘.
[1. 단어 CSV 자동 채움]
- CSV 업로드 시 pinyin·meaning_kr이 비어있는 단어에 대해 2단계 자동 채움:
- Step A: categorized_cihui → biaozhun_cihui 테이블에서 word 기준 매칭
- Step B: DB에서 못 찾은 단어만 Claude API 한 번 호출로 일괄 생성
- 교수자 직접 입력값은 자동 생성보다 우선 (덮어쓰지 않음)
- 미리보기 테이블: 각 단어에 출처 배지 (CSV 파란/DB 초록/AI 보라)
- 상단 요약: "총 N개 단어 | CSV 직접 입력: A개 | DB 자동 매칭: B개 | AI 생성: C개"
- [✅ 확인 및 저장 (N개)] 클릭 시에만 DB 저장
- 저장 후: 주차별 아코디언 목록 표시, 각 단어에 인라인 편집(✏) 및 삭제(🗑)
[2. AI 단어 보강]
- 단어 데이터 탭 [🤖 관련 단어 보강] 버튼 클릭
- Step 1: 주차 선택 모달 (각 주차에 현재 단어 수 표시, 예: "2주 차 (15개)")
- Step 2: 추천 어휘 목록 모달
- 제목: "추천 어휘 (N주차 보강)"
- 급수 필터 탭: 전체 / 1-2급 / 3-4급 / 5-6급 / 7~9급
- biaozhun_cihui DB에서 해당 주차에 미포함된 어휘 검색
- 각 어휘: 체크박스 + 한자 + 병음 + 한국어 뜻 + 급수 배지
- [선택한 어휘 추가 (N개)] 버튼 → curriculum_words에 INSERT
[3. 문장 CSV 자동 채움]
- CSV 업로드 시 pinyin·meaning_kr·words가 비어있는 문장에 대해 Claude API 호출
- 미리보기 테이블: 출처 배지 (CSV 파란/AI 보라)
- 상단 요약: "총 N개 문장 | CSV 직접 입력: A개 | AI 생성: B개"
- [✅ 확인 및 저장 (N개)] 클릭 시에만 DB 저장
- 저장 후: 주차별 아코디언 목록, 각 문장에 인라인 편집(✏) 및 삭제(🗑)
- 단어 분리(words)는 가운뎃점(·)으로 구분하여 표시
[4. AI 문장 생성]
- 문장 데이터 탭 [🤖 관련 문장 생성] 버튼 클릭 → 문장 생성 설정 모달:
- 주차 선택 (드롭다운, 현재 단어 수 표시. 예: "2주 차 (단어 15개)")
- 주차 선택 시 해당 주차 학습 내용(제목, 설명)과 등록 단어 목록 자동 표시
- 난이도 (드롭다운: 초급(1-3급) / 중급(4-5급) / 고급(6급+))
- 문장 길이 (드롭다운: 짧음 / 보통(일반적인 문장) / 길음)
- 어법 포인트 (텍스트 입력, 커리큘럼 설명에서 자동 채움 — 수정 가능)
- 생성 개수 (드롭다운: 3개 / 5개 / 10개)
- [취소] [🤖 문장 생성] 버튼
- Claude API로 해당 주차 어휘 기반 문장 자동 생성
[5. AI 강의 노트 생성]
- 강의 노트 탭: 15주 리스트, 각 주차에 제목(있으면) + 미생성(⚠)/생성됨 배지
- 미생성 주차 펼침 시: "이 주차의 강의 노트가 아직 생성되지 않았습니다." 안내
- 개별 [🤖 생성] 또는 [일괄 재생성] 클릭
- Claude API (Edge Function: generate-lecture-notes)로 주차당 6개 섹션 생성:
- 주차 제목 + 한글 해석, 학습목표 3개, 핵심 단어, 핵심 문장/회화(자동 구분), 어법 포인트(상세+예문 2개+highlight), 배정 게임 안내
- JSON 방식: Claude API 응답 → content_json(jsonb) 저장 → LectureNoteRenderer로 렌더링
- 섹션별 폼 편집 가능 (학습목표, 어법, 예문, highlight) - 🔊 Web Speech TTS (단어/문장/예문)
- 일괄 생성: 1주 차씩 순차 호출 + 2초 딜레이 (Rate Limit 대응)
- 학습자: /coach 오늘의 학습에서 [📄 강의 노트 보기] 모달 열람 + 인쇄
[주의사항]
- 기존 게임 코드, AuthContext는 변경하지 말 것
- AuthContext의 onAuthStateChange 콜백은 절대 async로 만들지 말 것
- 기존 RLS 정책은 변경하지 말 것
- 강의 노트 생성: Claude API — claude-haiku-4-5 (Edge Function: generate-lecture-notes, ANTHROPIC_API_KEY)
- 커리큘럼 생성: Gemini API — gemini-3.1-flash-lite-preview (Edge Function: generate-curriculum, GEMINI_API_KEY)
- 어휘 보완·문장 생성: Claude API (기존 프로젝트 API 키 사용)
자료에 관하여

이 페이지는 학위논문 제7장 7.3.1~7.3.2에서 다룬 커리큘럼 설계와 콘텐츠 보강 기능의 개발 기록 가운데, 지면에서 생략한 프롬프트 입력 기록과 개발 과정의 주요 화면을 수록한 것이다. 화면은 개발 당시의 기록이므로 현재의 웹앱과 다를 수 있다.

수록한 프롬프트는 실제 입력 기록이므로 문구를 사후에 고치지 않았다. 다만 인쇄 지면에 맞추어 줄이 나뉜 부분은 화면에서 읽기 쉽도록 다시 이어 붙였다.
