자료 01

[부록 표1-1] RISEN 프레임워크 기반 한자 연금술 S1 프롬프트 설계

RISEN 요소 · 한자 연금술 S1 적용
Role(역할)중국어 교육용 단어 조합 게임을 구현하는 React/TypeScript 웹앱 개발 전문가. 의뢰 시스템 기반 자원 관리 게임 메카닉스, 2단계 하이브리드 판정 로직, Web Audio API 효과음 구현에 정통한 전문가
Instructions(지시)의뢰인이 제시한 주제에 맞는 중국어 단어를 한자 카드 조합으로 만드는 게임을 구현한다. 의뢰서에는 목표 단어의 한국어 뜻만 표시하고 중국어는 숨긴다. 한자 카드를 용광로에 순서대로 투입하여 2~4자 단어를 조합하며, 2단계 하이브리드 판정(의뢰 목표 대조 + 동일 소분류 어휘 대조)으로 ‘틀림’ 없는 구조를 실현한다. 의뢰인 5종 캐릭터, 3단계 난이도 모드, 등급별 차등 보상, 카드 상점, 3단계 힌트, 막힘 감지, 콤보 배율을 구현한다. Web Audio API OscillatorNode로 효과음 7종을 코드 내에서 직접 생성한다. 따뜻한 황금빛 연금술사 작업실 테마를 적용하고 모바일 반응형 최적화를 수행한다
Steps(단계)① 시작 화면(칭호·의뢰인 5종 표시) + 난이도 선택 화면(수련생·연금술사·대사범 3단계) 구현, ② 의뢰 시스템(양피지 의뢰서·한국어 목표 태그·의뢰인 대사·난이도별 의뢰 수) 구현, ③ 한자 카드 풀 + 용광로 투입 인터랙션 구현, ④ 2단계 하이브리드 판정 로직 구현, ⑤ 카드 상점 + 3단계 힌트 + 막힘 감지 구현, ⑥ 등급별 차등 보상 + 콤보 배율 + 의뢰 정산 + 라운드 결과 화면 구현, ⑦ 비주얼 테마(황금빛 연금술사 작업실) 적용, ⑧ Web Audio API 효과음 7종 구현, ⑨ 하드코딩 샘플 데이터 포함, ⑩ 모바일 반응형 최적화
End goal(최종 목표)2단계 하이브리드 판정으로 ‘틀림’ 없는 구조를 실현하고, 따뜻한 황금빛 연금술사 작업실 테마와 효과음 7종이 적용된 교육용 단어 조합 게임의 기본 골격. 하드코딩 데이터로 즉시 플레이 가능하며, S3에서 DB 연동으로 전환할 수 있는 구조. 게임 플레이 중 AI API 호출은 0회이다
Narrowing(범위 한정)① 이 단계에서는 하드코딩 샘플 데이터로 동작하며 Supabase DB 연동은 S3에서 수행한다. ② 도감·칭호·TTS는 S2에서 구현한다. ③ 게임 플레이 중 외부 AI API 호출은 0회이다. ④ 효과음은 Web Audio API로 코드 내에서 생성하여 외부 파일 의존이 없다. ⑤ 기존 다른 게임 코드, Supabase 테이블 스키마, 메인 허브 코드를 일체 수정하지 않는다

RISEN 요소 · 한자 연금술 S2 적용

Instructions(지시)S1의 게임 본체에 다음 기능을 추가한다. 연금 성공 단어를 자동 수집하는 어휘 도감(9,456개 단어 대비 수집률 표시, 등급별 필터, 카드 그리드, CSS 3D flip 상세 보기)을 구현한다. 도감 수집 수에 따라 7단계로 성장하는 칭호 시스템을 구현한다. Web Speech API로 도감 카드에서 중국어 발음을 재생하는 TTS 기능을 추가한다
Steps(단계)① 어휘 도감 화면 구현(상단 수집률 "N/9,456개", 등급별 탭 필터, 카드 그리드 데스크톱 4열·모바일 2열), ② 수집 카드 앞면 + 미수집 카드 구현, ③ CSS 3D flip 뒤집기 구현, ④ 칭호 7단계(견습→초급→숙련→고급→마스터→전설→대현자) 구현, ⑤ 연금 성공 시 도감 자동 수집 구현, ⑥ Web Speech API TTS 구현
End goal(최종 목표)9,456개 단어 수집 도감, 7단계 칭호 성장, CSS 3D flip 카드 상세 보기, TTS 발음 재생이 추가된 이중 동기 체계 완성

프롬프트 표에 나타나는 ‘어휘 도감’은 실제 입력 시점의 명칭이며, 웹앱에서는 이후 ‘단어 도감’으로 변경되었다. 프롬프트 표는 실제 입력 기록이므로 원문 그대로 제시한다.
