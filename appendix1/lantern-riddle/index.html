자료 01

[부록 표3-1] RISEN 프레임워크 기반 등불 수수께끼 콘텐츠 생성 프롬프트 설계

RISEN 요소 · 등불 수수께끼 적용
Role(역할)중국 등미 문화 전문가이자 한자학 교수. 전통 등미의 5가지 풀이법(拆字法, 增损法, 会意法, 象形法, 离合法)에 정통하며, 한국인 중국어 학습자의 수준에 맞는 수수께끼를 출제하는 전문가.
Instructions (지시)① 주어진 한자에 대해 지정된 유형의 수수께끼 단서[谜面]를 한국어로 생성한다. ② 단서는 한자의 실제 구조적 특성을 정확히 반영해야 한다. ③ 풀이 해설(谜底解析)을 단계별로 작성한다. ④ 초급(1~3급)은 사지선다 선택지를 생성한다. ⑤ 3단계 힌트를 유형별로 작성한다.
Steps(단계)등급별 한자 목록 수신 → 한자 구조 분석 → 수수께끼 유형 배정 → 단서[谜面] 생성 → 풀이 해설 작성 → 선택지·힌트 생성 → CSV 출력 → 인간 전수 검수 → 오류 수정 → DB 업로드
End goal(최종 목표)480개 검증된 수수께끼 DB: 게임 중 API 호출 없이 안정적 서비스
Narrowing(범위 한정)《等级标准》1~9급 한자만 사용, 단서는 한국어, 5가지 수수께끼 유형만 적용, 등급별 유형 비율 가이드 준수, 정답은 반드시 한자 1자

자료 02

[부록 표3-2] RISEN 프레임워크 기반 등불 수수께끼 S1 프롬프트 설계

RISEN 요소 · 등불 수수께끼 S1 적용
Role(역할)중국 전통 등불축제(元宵节)의 등미 놀이를 디지털 추론 퍼즐로 구현하는 React/TypeScript 웹앱 개발 전문가. Supabase 기반 데이터베이스 설계, 모바일 퍼스트 UI, Web Audio API 효과음, Web Speech API TTS에 정통하다
Instructions (지시)dengmi_all_levels.csv(480개 수수께끼)를 Supabase에 업로드하고, 4개 테이블(dengmi_stages, dengmi_records, dengmi_notebook, dengmi_progress)을 생성한 뒤, 축제 거리 메인·등불 거리·수수께끼 풀이 모달·수수께끼 수첩·칭호의 5개 화면으로 구성된 등불 수수께끼 게임을 구현한다
Steps(단계)① CSV 데이터 업로드(480개 → dengmi_stages), ② Supabase 4개 테이블 생성 및 RLS 설정, ③ 축제 거리 메인 화면, ④ 등불 거리 화면(그리드 배치), ⑤ 수수께끼 풀이 모달(사지선다 / 타이핑 + 3단계 힌트 + 오답 재도전), ⑥ 점수 계산 로직, ⑦ 수수께끼 수첩(TTS), ⑧ 칭호 5단계, ⑨ 효과음(Web Audio API), ⑩ 메인 허브 카드 연결
End goal(최종 목표)480개 수수께끼가 Supabase에 저장되고, 시간 제한 없는 추론 퍼즐 환경에서 초급 사지선다와 중급 이상 한자 타이핑을 지원하며, 3단계 힌트·등불 점등 애니메이션·수수께끼 수첩·칭호 5단계가 작동하는 등불 수수께끼 게임. 게임 플레이 중 AI API 호출은 0회이다
Narrowing(범위 한정)① 기존 게임 코드 수정 금지, ② 시간 제한 없음, ③ 게임 플레이 중 외부 API 호출 없음(0회)
자료 03

[부록 표3-3] 등불 수수께끼 1단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
SQL 테이블 생성dengmi_stages, dengmi_records, dengmi_notebook, dengmi_progress의 4개 테이블 컬럼 정의. RLS: stages 전체 읽기, 나머지 3개 테이블 사용자별
CSV 데이터 적재dengmi_all_levels.csv(480행) 업로드. 컬럼 18개: id, hanzi, pinyin, meaning, level, stage_in_level, riddle_type, riddle_type_label, riddle_type_icon, riddle_text, riddle_scope, explanation, structure_note, hint_1~3, choices, difficulty
수수께끼 풀이 모달초급(1~3급) 사지선다 버튼(choices 필드, 정답 위치 매번 셔플). 중급 이상(4~7~9급) 한자 타이핑 입력(inputMode="text", lang="zh"). trim() 처리, 정확히 1자 일치 판정
3단계 힌트 시스템hint_1: 유형별 풀이 방향 안내. hint_2: 구조 힌트(부수·획수). hint_3: 병음+성조. 순차 활성화, 사용 후 화면 유지
오답 처리1차: 재도전. 2차: 힌트 1 자동 표시+재도전. 3차: 정답 공개+해설 카드+기본 점수 20%
점수 계산등급별 기본 점수(1급 5점~7~9급 50점). 무힌트 ×1.5, 빠른 풀이(15초 ×1.4, 30초 ×1.2), 콤보(3연속 ×1.5, 5연속 ×2, 10연속 ×3)
등불 점등 시각 효과정답 시 어두운 등불→밝은 빨간+글로우 확산(0.8초)+폭죽 이펙트(1.5초). 3차 오답 정답 공개 시 반점등(opacity: 0.5)
화면 구성축제 거리 메인(등급별 카드), 등불 거리(5열 그리드, 자유 선택), 풀이 모달(양피지 배경), 수수께끼 수첩(등급별 아코디언+TTS), 칭호(5단계)
게임 흐름축제 거리(등급 선택) → 등불 거리(등불 탭) → 풀이 모달(단서 분석→정답 입력→해설) → 수첩 수집

자료 04

[부록 표3-4] RISEN 프레임워크 기반 등불 수수께끼 S2 프롬프트 설계

RISEN 요소 · 등불 수수께끼 S2 적용
Role(역할)S1으로 구현된 등불 수수께끼 게임의 레이아웃을 재구성하고, 2건의 버그를 수정하며, 등미 문화 안내 배너를 추가하여 게임을 완성하는 React/TypeScript 웹앱 개발 전문가
Instructions (지시)(1) 메인 화면 레이아웃 재구성(수첩·칭호 상단 2열 카드, 초급·중급·고급 그룹핑, 하단 탭 제거), (2) "다음 등불" 클릭 시 이전 정답이 보이는 버그 수정(RiddleModal key 리마운트), (3) X 버튼으로 닫아도 정답 기록 저장되도록 수정, (4) 메인 화면에 등미 문화 안내 배너 추가(접이식)
Steps(단계)① 수첩·칭호 상단 가로 2열 카드 이동, ② 등급 목록 초급·중급·고급 그룹핑, ③ 하단 탭 제거, ④ RiddleModal key={selectedStage.id} 추가, ⑤ X 버튼 handleClose 함수 추가, ⑥ 등미 문화 안내 배너(접이식), ⑦ 등불 거리 배너 제거
End goal(최종 목표)레이아웃 재구성, 버그 수정, 문화 안내 배너가 적용된 완성된 등불 수수께끼 게임
Narrowing(범위 한정)① S1의 게임 로직 변경 금지. ② 테이블 구조 변경 금지. ③ 기존 다른 게임 코드 수정 금지.

[부록 표3-5] 등불 수수께끼 2단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
레이아웃 재구성수첩·칭호를 하단 탭에서 상단 가로 2열 카드로 이동. 등급 목록을 초급·중급·고급 3개 그룹으로 분류. 하단 탭 완전 제거

자료에 관하여

이 페이지는 학위논문 부록 1 가운데 3.4 한자 수수께끼 게임: 등불 수수께끼의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
