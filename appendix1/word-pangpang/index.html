RISEN 프롬프트 설계와 Lovable 입력 프롬프트의 핵심 지시

자료 01

[부록 표10-1] RISEN 프레임워크 기반 단어 팡팡 S1 프롬프트 설계

RISEN 요소 · 단어 팡팡 S1 적용
Role(역할)중국어 교육 게임 설계자이자 React 웹앱 개발 전문가. Supabase 데이터베이스 설계와 풍선 UI 기반 배치형 게임 구현에 정통한 전문가
Instructions (지시)Supabase에 4개 테이블을 생성하고 4개 CSV를 통합 적재한다. 월드 선택, 게임 플레이, 게임 오버의 3화면 웹앱을 구현한다. 라운드마다 6개 풍선을 3×2 그리드로 배치하고, 풍선 탭 시 마이크 녹음을 시작한다. 발음 판정은 시뮬레이션(70% 확률 정답)으로 우선 구현한다. 가중 랜덤 출제, 라이프 5개 시스템, 콤보를 구현한다
Steps(단계)① Supabase에 4개 테이블 생성 및 CSV 데이터 적재, ② 3화면 구조 웹앱 생성, ③ 6개 풍선 3×2 그리드 배치 및 부유 애니메이션, ④ 풍선 탭 → 마이크 녹음 → 시뮬레이션 판정, ⑤ 풍선 터짐 이펙트 및 오답 시 라이프 감소, ⑥ 가중 랜덤 출제 로직, ⑦ 콤보·배지·점수·게임 오버 모달 구현
End goal(최종 목표)4개 월드로 구성된 배치형 연속 라운드 단어 발음 게임의 기본 골격. 시뮬레이션 판정으로 작동하는 프로토타입
Narrowing(범위 한정)① 발음 판정은 시뮬레이션만 구현한다(Azure 연동은 S2). ② 배경 이미지는 적용하지 않는다. ③ 배경음악은 마이크 녹음 품질 보호를 위해 배제한다
자료 02

[부록 표10-2] 단어 팡팡 1단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
SQL 테이블 생성pangpang_words(11,047행), user_progress, user_badges, sessions의 4개 테이블을 생성한다. 4개 월드의 CSV를 통합하여 pangpang_words 단일 테이블에 적재하고, syllable_count 컬럼으로 월드를 구분한다
풍선 배치라운드마다 6개 풍선을 3×2 그리드로 배치한다. 각 풍선은 둥근 사각형 카드 형태로, 한자(큰 글씨)와 병음(작은 글씨)을 표시한다. 다음자 풍선(is_polyphonic='Y')에는 한국어 뜻 힌트를 병기한다. 급수별 7색 차별화(1급 파랑~7~9급 빨강)
시뮬레이션 판정Web Speech API(SpeechRecognition)로 음성 인식 후, 70% 확률 정답으로 판정한다. 정답 시 풍선 터짐 이펙트(scale+파티클), 오답 시 라이프 -1 + 풍선 유지(재시도 가능)
가중 랜덤 출제current_level에서 50%, ±1급에서 15%/20%, ±2급에서 5%/10% 가중. 연속 정답 5회 시 급수 +1(최대 7), 오답 시 급수 -1(최소 1)
라이프 시스템초기 5개(❤×5), 오답 시 -1, 0이 되면 게임 오버. 회복 없음
게임 흐름월드 선택(4개 카드, 최고 점수·라운드·콤보) → 게임 플레이(HUD + 풍선 6개 + 마이크 버튼) → 게임 오버 모달(통계 + 다시 도전/월드 선택)

2단계(S2) 프롬프트

RISEN 프롬프트 설계와 Lovable 입력 프롬프트의 핵심 지시

자료 03

[부록 표10-3] RISEN 프레임워크 기반 단어 팡팡 S2 프롬프트 설계

RISEN 요소 · 단어 팡팡 S2 적용
Role(역할)중국어 교육 게임 설계자이자 음성 인식 기술 전문가. Azure Pronunciation Assessment를 활용한 어휘 발음 판정 시스템과 Azure Neural TTS 캐싱 구조를 설계할 수 있는 전문가
Instructions (지시)S1의 시뮬레이션 판정을 Azure Pronunciation Assessment 실시간 판정으로 교체한다. 월드1·2는 임계값 85점, 월드3·4는 80점으로 차등 적용한다. 풍선을 CSS 렌더링으로 전환하고, Azure Neural TTS 캐싱, 오답 노트, 배지 10종, 2회 연속 오답 자동 스킵을 구현한다
Steps(단계)① CSS 풍선 전환(급수별 7색), ② 병음 힌트 토글, ③ 풍선 탭 즉시 녹음, ④ Azure Pronunciation Assessment 연동(월드별 임계값 차등), ⑤ Azure Neural TTS + 캐싱, ⑥ 효과음, ⑦ 오답 노트, ⑧ 배경 이미지 4장 적용, ⑨ 배지 10종, ⑩ 통계 테이블 추가 + 매 라운드 저장, ⑪ 2회 연속 오답 자동 스킵
End goal(최종 목표)Azure Pronunciation Assessment 기반 실시간 발음 판정(월드별 임계값 차등), Azure Neural TTS 캐싱, 11,047개 단어 풀에서 무한 리플레이 가능한 단어 발음 게임
Narrowing(범위 한정)① 성조 클라임의 Edge Function을 재사용한다. ② 동일 단어 2회 연속 오답 시 라이프 소모 없이 자동 스킵한다. ③ 시간 압박 없이 학습자 페이스로 진행한다
자료 04

[부록 표10-4] 단어 팡팡 2단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
Azure PA 연동성조 클라임의 Edge Function(evaluate-pronunciation)을 재사용한다. 풍선 탭 → 즉시 녹음 → WAV → Edge Function → AccuracyScore. 월드1·2는 임계값 85점, 월드3·4는 80점으로 차등 적용한다
CSS 풍선 전환이미지 풍선을 CSS로 교체한다. 급수별 7색(1급 #3B82F6~7~9급 #EF4444), border-radius 16px, 부유 애니메이션. 한자+급수 배지+뜻 힌트(다음자만)
풍선 탭 즉시 녹음풍선 탭 시 즉시 MediaRecorder 녹음 시작. 별도 마이크 버튼 제거. 다시 탭 또는 3초 후 자동 종료 → 판정
Azure Neural TTS 캐싱오답 시 zh-CN-XiaoxiaoNeural로 정답 발음 재생. base64 캐싱하여 오답 노트에서 API 0회 재생. Azure 실패 시 Web Speech API 폴백
오답 노트성조 클라임 스타일 통일. 한자+병음+뜻+음절별 정확도 바+TTS 버튼. 2열 그리드(모바일 1열). 세션 메모리
2회 오답 스킵동일 풍선 2회 연속 오답 시 라이프 소모 없이 자동 스킵. 풍선이 하늘로 날아가는 애니메이션(translateY -200px, opacity 0). Azure 다음자 오판정 대응
배경·배지·통계Cloudinary 배경 이미지 4장(월드별). 배지 10종. pangpang_user_stats 테이블 추가 + 매 라운드 통계 자동 저장
자료에 관하여

이 페이지는 학위논문 부록 1 가운데 5.3 단어 발음 게임: 단어 팡팡의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
