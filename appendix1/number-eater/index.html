RISEN 요소 · 숫자 먹깨비 S2 적용
Role(역할)S1으로 구현된 숫자 먹깨비 게임에 AI 생성 이미지 12장을 적용하고, 3단계 힌트 시스템, Web Audio API 효과음, 도감 상세 팝업, Canvas 렌더링 최적화를 적용하여 게임을 완성하는 React/TypeScript 웹앱 개발 전문가
Instructions (지시)Supabase Storage에 업로드한 플레이어 4방향·유령 4종·겁먹은 유령·배경 2종·파워 펠릿의 12장 이미지를 Canvas drawImage로 적용한다. 배경 이미지 위에 불투명 Canvas 렌더링과 적갈색 벽·반투명 길로 가독성을 확보한다. 월드2에 3단계 힌트 시스템(한국어 뜻 공개, 정답 이모지 glow, 전체 정답 glow)을 구현한다. Web Audio API로 효과음 4종을 코드 내에서 직접 생성한다. 도감에 양사별 명사 목록과 발음 재생 기능을 추가한다
Steps(단계)① Supabase Storage에 12장 이미지 업로드 및 Canvas drawImage 적용(프리로드 포함), ② 배경 이미지 CSS 적용 + Canvas 불투명 렌더링 + 벽·길 스타일, ③ 캐릭터 크기 조정(플레이어 ×1.3, 유령 ×1.2), ④ 3단계 힌트 시스템 구현(뜻 공개 → 정답 이모지 1개 glow → 전체 정답 glow), ⑤ Web Audio API 효과음 4종 구현, ⑥ 도감 상세 팝업 구현(양사별 명사 목록 + TTS 발음 재생), ⑦ 시각 최적화(외곽 배치 금지, 한자 글자 수별 폰트 자동 축소 등)
End goal(최종 목표)AI 생성 이미지, 3단계 힌트, 효과음, 도감 TTS가 모두 적용된 숫자 먹깨비 최종 완성판. 2개 월드 × 22개 스테이지에서 숫자 순서 인지와 양사 결합 규칙을 훈련하며, 게임 플레이 중 API 호출은 0회이다
Narrowing(범위 한정)S1에서 구현한 Canvas 게임 루프, 영역 방어형 유령 AI, 타일 단위 이동, HP 게이지, 파워 펠릿, 콤보 배율, 별 평가 기준, 월드별 학습 메카닉스는 변경하지 않는다. DB 테이블 스키마를 변경하지 않는다. 게임 플레이 중 API 호출은 0회이다

[부록 표7-4] 숫자 먹깨비 2단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
AI 이미지 적용ChatGPT Image로 생성한 12장(플레이어 4방향 4장, 요괴 유령 4종 4장, 겁먹은 유령 1장, 월드별 배경 2장, 파워 펠릿 1장)을 Supabase Storage pacman-images 버킷에 업로드. Canvas drawImage로 렌더링 교체. 이미지 프리로드: Promise.all로 12장 병렬 로딩 후 게임 시작
월드3 삭제가격 쇼핑가(价格街) 삭제. 화폐 합산이 단순 계산에 그쳐 학습적 흥미 급감, 팩맨 게임 경험과 부합하지 않음. 3개 월드 28스테이지에서 2개 월드 22스테이지로 축소

월드2 메카닉스 재설계1차: HUD 이모지→미로 양사 한자 → 2차: HUD 양사→미로 이모지 → 3차(최종): HUD에 양사 한자+병음 제시, 미로에 정답 이모지 + 방해 이모지(정답의 50%, 다른 양사 그룹) 배치. 정답만 자동 수집, 오답 통과 시 페널티 없음

3단계 힌트스테이지당 3회. 1단계: 한국어 뜻 공개(별 최대 ⭐⭐), 2단계: 정답 이모지 1개 glow 5초(별 최대 ⭐), 3단계: 전체 정답 glow 5초(별 최대 ⭐). Glow: shadowColor 'rgba(255,255,0,0.9)', shadowBlur 10~25 Math.sin 애니메이션

도감 상세 팝업양사 항목 탭 시 팝업: 양사 한자(text-4xl) + 병음 + 한국어 뜻 + 함께 쓰이는 명사 목록(이모지+한자+병음+뜻+◻). TTS: speechSynthesis lang='zh-CN' rate=0.8
자료에 관하여

이 페이지는 학위논문 부록 1 가운데 4.4 수량 표현 게임: 숫자 먹깨비의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
