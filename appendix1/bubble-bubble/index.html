자료 01

[부록 표2-1] RISEN 프레임워크 기반 버블버블 S1 프롬프트 설계

RISEN 요소 · 버블버블 S1 적용
Role(역할)중국어 교육용 버블 터뜨리기 게임을 구현하는 React/TypeScript 웹앱 개발 전문가. Supabase 기반 데이터베이스 설계, 버블 물리 엔진, 순서 기반 정답 판정, 해저 테마 UI에 정통한 전문가
Instructions (지시)Supabase에 3개 테이블(stages, user_progress, user_stats)을 생성하고 979개 스테이지 CSV를 적재한다. 메인 화면, 스테이지 선택, 게임 플레이, 클리어, 문장 수첩, 배지의 6개 화면을 구현한다. 화면에 떠다니는 버블 중 목표 문장의 단어를 정확한 순서대로 탭하면 클리어하고, 방해 버블 탭 시 시간 3초, 순서 틀림 시 2초를 차감하는 게임 메커니즘을 구현한다. 하트 시스템(최대 5개, 30분 회복), 3단계 별 평가, 등급 해금(80%), 병음 힌트 토글, 첫 글자 힌트, 문장 수첩 자동 수집, 등급별 배지를 구현한다. 해저 테마 디자인을 적용하고 모바일 반응형 최적화를 수행한다
Steps(단계)① Supabase에 stages(979행, 읽기 전용), user_progress(사용자별 클리어 기록), user_stats(하트·해금·별 통계) 3개 테이블 생성 및 RLS 설정, ② 979개 스테이지 CSV 데이터 적재, ③ 6개 화면 구현(메인→스테이지 선택→게임 플레이→클리어→문장 수첩·배지), ④ 버블 물리 엔진(랜덤 이동, 벽 반사, 등급별 속도 증가) 구현, ⑤ 순서 기반 정답 판정 + 오답 시간 차감 페널티 구현, ⑥ 하트 시스템(최대 5개, 시간 초과 시 -1, 30분 회복) 구현, ⑦ 3단계 별 평가 + 등급 해금(80%) + 등급별 해저 테마 배지 구현, ⑧ 병음 힌트 토글(무료) + 첫 글자 힌트(스테이지당 1회) 구현, ⑨ 문장 수첩 자동 수집(중국어 원문·병음·한국어 번역·별·문법 항목) 구현, ⑩ 해저 테마 디자인(짙은 파란 배경, 버블 파티클) + 모바일 반응형 최적화
End goal(최종 목표)7개 등급 979개 스테이지로 구성된 버블버블 게임의 기본 골격. 979개 스테이지 데이터가 Supabase에 적재되어 게임 플레이 중 API 호출 없이 DB 조회만으로 콘텐츠를 제공하며, 11개 게임 메커니즘과 6개 화면이 해저 테마로 구현된 교육용 문장 배열 게임
Narrowing(범위 한정)게임 플레이 중 외부 AI API 호출은 0회이다. stages 테이블은 읽기 전용이며 게임 중 변경하지 않는다. 기존 다른 게임 코드, Supabase 테이블 스키마, 메인 허브 코드를 일체 수정하지 않는다
자료 02

[부록 표2-2] 버블버블 1단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
SQL 테이블 생성stages(id TEXT PK, level, stage_in_level, grammar_item, sentence, display_sentence, words TEXT[], word_count, pinyin TEXT[], distractors TEXT[], total_bubbles), user_progress(user_id FK, stage_id FK, cleared, stars, best_time, mistakes, attempts, UNIQUE(user_id, stage_id)), user_stats(user_id PK, current_level, total_cleared, total_stars, hearts DEFAULT 5, hearts_updated_at). RLS: stages 전체 읽기, progress·stats 사용자별
CSV 데이터 적재stages_upload_korean_completed.csv(979행) → stages 테이블. 컬럼: id, level, stage_in_level, grammar_item, sentence, display_sentence, words, word_count, pinyin, distractors, total_bubbles, korean_translation
6개 화면① 메인: 로고 "🫧 Bubble Bubble", 하트 표시, 총 별, Level 1~7 카드 리스트(진행률 바, 해금/잠금), 하단 [📖 문장 수첩] [🏅 배지]. ② 스테이지 선택: 그리드 5열, 별 색상(회색→청록→파랑→금색), 등급 내 자유 선택. ③ 게임 플레이: 상단 바(Stage, 하트, 타이머), 목표 문장+빈 슬롯, 버블 영역, 하단 힌트 버튼. ④ 클리어: 별 평가, 문장·병음·번역·문법 항목, 소요 시간·오답 횟수. ⑤ 문장 수첩: 등급별 분류, 별·원문·병음·번역. ⑥ 배지: 해저 테마 7종
버블 물리 엔진정답+방해 = 8~16개 버블 배치. requestAnimationFrame 기반 이동. 벽 반사(bouncing). 등급별 속도 증가(Level 1 느림→Level 7 빠름). 모바일 터치 + 데스크톱 클릭 대응
정답 판정+ 오답 페널티상단 목표 문장의 단어를 순서대로 탭. 정답 탭 시 버블 터짐+슬롯 채움 애니메이션. 방해 버블 탭→시간 -3초+✕ 표시. 순서 틀림→시간 -2초. 시간 초과→하트 -1
시간 제한2~4단어 20초, 5~6단어 30초, 7~8단어 40초, 9~10단어 50초. 카운트다운 프로그레스 바
하트 시스템최대 5개. 시간 초과 시 -1. 30분마다 +1 회복(hearts_updated_at 기준 계산). 0개 시 플레이 불가
별 평가+ 등급 해금⭐ 클리어, ⭐⭐ 오답 1회 이하, ⭐⭐⭐ 오답 0회+시간 50% 이내. 다음 등급 진입 = 현재 등급 80% 클리어
힌트 시스템병음 힌트: 무료 토글(버블 위에 병음 표시/숨김). 첫 글자 힌트: 스테이지당 1회, 다음 정답 단어의 첫 글자 강조
문장 수첩클리어 문장 자동 수집. 등급별 접기/펼치기. 각 문장: 별 등급, 중국어 원문, 병음, 한국어 번역. 수집률 "979개 중 N개" 표시
배지 시스템등급 완료 시 해저 테마 배지 7종(1급 🐠 마스터, 2급 🐡 탐험가, 3급 🐟 항해사, 4급 🦑 잠수부, 5급 🐙 심해사, 6급 🐋 대왕고래, 7~9급 🐉 정복자). 획득/미획득 표시
해저 테마 디자인짙은 파란 배경(#0a1628). 버블 파티클 애니메이션. 클리어 시 수중 축하 이펙트
모바일 최적화모바일 퍼스트(터치 기반). 버블 최소 44px 터치 영역. 반응형 그리드. safe-area-inset 대응

2단계(S2) 프롬프트

RISEN 프롬프트 설계와 Lovable 입력 프롬프트의 핵심 지시

자료 03

[부록 표2-3] RISEN 프레임워크 기반 버블버블 S2 프롬프트 설계

RISEN 요소 · 버블버블 S2 적용
Role(역할)S1으로 구현된 버블버블 게임의 버그를 수정하고 기능을 완성하는 React/TypeScript 웹앱 개발 전문가
Instructions (지시)S1에서 발생한 다음 버그를 수정한다. (1) 다음 스테이지 버튼이 스테이지 선택 화면으로 돌아가는 오류, (2) 클리어 화면에 한국어 번역이 표시되지 않는 오류, (3) 스테이지 이동 시 게임 상태가 초기화되지 않는 오류, (4) 등급 해금 조건(80%) 판정 오류, (5) 문장 수첩 수집 데이터 누락, (6) 하트 회복 타이머 계산 오류, (7) 별 평가 조건 판정 오류
Steps(단계)① 다음 스테이지 버튼의 navigate 경로를 다음 스테이지 플레이 화면으로 수정, ② 클리어 화면에 korean_translation 필드 표시 추가, ③ 스테이지 전환 시 타이머·버블·슬롯 상태 전부 초기화, ④ 해금 판정 로직을 cleared === true인 스테이지 수 / 해당 등급 전체 스테이지 수 ≥ 0.8로 수정, ⑤ 클리어 시 문장 수첩에 자동 저장하는 로직 추가, ⑥ hearts_updated_at 기준 경과 시간 계산 및 최대 5개 상한 적용, ⑦ 별 평가 조건을 설계 기준(⭐ 클리어, ⭐⭐ 오답 1회 이하, ⭐⭐⭐ 오답 0회+시간 50% 이내)과 일치하도록 수정
End goal(최종 목표)7개 버그가 모두 수정되어 11개 게임 메커니즘이 설계대로 정상 작동하는 버블버블 최종 완성판. 979개 스테이지에서 340종 문법 항목을 학습할 수 있으며, 게임 플레이 중 API 호출은 0회이다
Narrowing(범위 한정)S1에서 구현한 버블 물리 엔진, 해저 테마 디자인, 6개 화면 구조를 변경하지 않는다. DB 테이블 스키마를 변경하지 않는다. 기존 다른 게임 코드·메인 허브를 수정하지 않는다. 게임 플레이 중 API 호출은 0회이다
자료 04

[부록 표2-4] 버블버블 2단계 프롬프트 핵심 수정 지시

구현 영역 · 핵심 지시 내용
다음 스테이지 버튼클리어 화면의 "다음 스테이지" 버튼이 스테이지 선택 화면으로 돌아가는 문제 수정. navigate 경로를 /play/{nextStageId}로 변경하여 다음 스테이지로 직접 이동
한국어 번역 표시클리어 화면에 한국어 번역이 표시되지 않는 문제 수정. stages 테이블의 korean_translation 필드를 클리어 화면 컴포넌트에 바인딩
게임 상태 초기화스테이지 이동 시 이전 스테이지의 버블·타이머·슬롯 상태가 잔존하는 문제 수정. useEffect cleanup에서 타이머 clear + 상태 전부 초기화
등급 해금 판정80% 해금 조건의 분모가 잘못 계산되는 문제 수정. 해당 등급 전체 스테이지 수 대비 cleared===true 스테이지 수로 판정
문장 수첩 수집클리어 시 문장 수첩에 데이터가 저장되지 않는 문제 수정. 클리어 핸들러에서 user_progress UPSERT 직후 수첩 데이터 저장 로직 추가
하트 회복 타이머30분 회복 계산이 부정확한 문제 수정. hearts_updated_at 기준 경과 분÷30으로 회복 수 계산, 최대 5개 상한 적용, 회복 시 hearts_updated_at 갱신
별 평가 조건별 평가 기준이 설계와 불일치하는 문제 수정. ⭐ 클리어, ⭐⭐ mistakes ≤ 1, ⭐⭐⭐ mistakes === 0 && 소요시간 ≤ 제한시간×0.5
자료에 관하여

이 페이지는 학위논문 부록 1 가운데 3.3 문장 배열 게임: 버블버블의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
