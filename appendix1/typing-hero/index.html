자료 01

[부록 표4-1] RISEN 프레임워크 기반 타자 히어로 S1 프롬프트 설계

RISEN 요소 · 타자 히어로 S1 적용
Role(역할)React/TypeScript 웹앱 개발자이자 중국어 교육용 타이핑 게임 설계자. 기존 코드를 전삭제하고 어휘 기반 타이핑 디펜스 게임을 재구축하는 전문가.
Instructions (지시)① 기존 타자 히어로 관련 코드·테이블을 전부 삭제한다. ② Supabase의 기존 categorized_cihui 테이블(9,456행)을 읽기 전용 어휘 데이터로 직접 활용한다. ③ 단어 낙하, 병음 타이핑, 자동 매칭, 격퇴의 단일 메카닉스 타이핑 디펜스 게임을 구현한다. ④ 급수별 스테이지 자동 생성(런타임), 콤보, 별 평가, HP 시스템을 구현한다. ⑤ 3개 화면(급수 선택, 스테이지 선택, 전투)과 2개 모달(클리어, 실패)로 구성한다
Steps(단계)① 기존 타자 히어로 컴포넌트·훅·타입·유틸 전삭제 및 기존 DB 테이블 삭제, ② th_user_progress·th_user_stats 2개 테이블 신규 생성(RLS 적용), ③ categorized_cihui에서 전체 어휘 로드 및 메모리 캐시와 병음 정규화 함수 구현, ④ 급수별 스테이지 자동 분할(10/15/20개) 및 셔플 로직 구현, ⑤ CSS transition 기반 단어 낙하와 시간차 스폰(2.5초 간격, 최대 3체) 및 방어선 도달 판정 구현, ⑥ 병음 입력, 자동 매칭(가장 아래쪽 우선), 격퇴 판정과 콤보·HP·별 평가 구현, ⑦ 3개 화면 UI 구현 및 클리어·실패 모달, ⑧ 모바일 소프트 키보드 대응(visualViewport API)
End goal(최종 목표)categorized_cihui 9,456개 단어를 603개 스테이지로 자동 분할하여, 학습자가 1급부터 7~9급까지 전체 어휘의 병음을 타이핑 디펜스 게임으로 학습할 수 있는 완전한 웹앱. 게임 플레이 중 외부 API 호출 0회
Narrowing(범위 한정)① 기존 게임(한자 연금술, 버블버블, 등불 수수께끼, 메인 허브) 코드 수정 금지, ② 모드는 캠페인만 구현(연습, 도전, 상점, 스킬 없음), ③ 동음 선택 UI 없음(동음 단어는 가장 아래쪽 자동 매칭), ④ 스테이지 데이터는 DB 사전 저장 없이 런타임 생성
자료 02

[부록 표4-2] 타자 히어로 1단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
기존 코드 삭제타자 히어로의 모든 컴포넌트·페이지·훅·타입·유틸 파일 삭제. 기존 Supabase 테이블(th_pinyin_hanzi_map, th_homophone_groups 등 10개) 전부 삭제
SQL 테이블 생성th_user_progress(user_id, grade, stage, stars, best_accuracy, best_combo, clear_time, cleared, cleared_at), th_user_stats(user_id, current_grade, total_cleared, total_stars, total_kills, best_combo, overall_accuracy). RLS: auth.uid() = user_id
단어 데이터 활용categorized_cihui 테이블(9,456행) 그대로 사용. 앱 시작 시 전체 로드하여 메모리 캐시. 신규 테이블 생성 없음
병음 정규화normalizePinyin 함수: 파이프→첫 번째 변형만, 슬래시·공백 제거, 성조 부호를 알파벳으로 변환, 소문자 통일
스테이지 자동 생성급수별 config(1~3급 10어, 4~6급 15어, 7~9급 20어). 단어 슬라이스 후 매 플레이 시 Fisher-Yates 셔플
단어 낙하CSS transition 방식. DOM 직접 생성, 3열 분산(15%·45%·75%). 방어선: 낙하 시간의 85% 지점에서 HP 감소 판정
시간차 스폰최대 활성 적 3체, 2.5초 간격 순차 스폰(setTimeout 체인). 큐 소진 및 활성 적 0이면 스테이지 클리어
병음 매칭입력 정규화 후 활성 적 중 pinyinClean 일치하는 적 탐색. getBoundingClientRect().top이 가장 큰(아래쪽) 적 우선 매칭
게임 요소콤보(5+, 10+COMBO!, 20+ON FIRE!, 30+UNSTOPPABLE!), HP 5(♥ 하트 아이콘), 별 평가(1★ 클리어, 2★ 정확도 80%+, 3★ 정확도 95%+콤보 10+)
화면 구성급수 선택(7개 카드, 해금 조건), 스테이지 선택(5열 그리드), 전투(상단 바+전투 필드+입력 영역, max-w-500px, h-100dvh). 클리어·실패 모달
모바일 대응visualViewport API로 소프트 키보드 감지하여 CSS 변수로 컨테이너 높이 조정. React 상태 대신 DOM 직접 조작(리렌더 방지)

RISEN 프롬프트 설계와 Lovable 입력 프롬프트의 핵심 지시

자료 03

[부록 표4-3] RISEN 프레임워크 기반 타자 히어로 S2 프롬프트 설계

RISEN 요소 · 타자 히어로 S2 적용
Role(역할)React/TypeScript 웹앱 개발자이자 게임 메카닉스 설계자. S1에서 구현된 타이핑 디펜스 게임의 게임성 강화, 모바일 안정화, 비주얼 완성을 담당하는 전문가
Instructions (지시)① 스테이지별 낙하 속도 가속 공식을 적용하여 난이도 곡선을 구현한다. ② 특수 단어 프리즈 메카닉스를 추가한다. ③ CSS transition을 @keyframes animation으로 전환하여 모바일 안정성을 확보한다. ④ Web Audio API 기반 효과음 7종을 코드로 생성한다. ⑤ fal.ai로 생성한 급수별 배경 이미지 7종을 적용한다
Steps(단계)① 어휘 셔플 적용 및 급수별 게임 내 명칭 반영, ② 스테이지별 낙하 속도 가속 공식 구현(급수 내 첫→마지막 스테이지 선형 보간), ③ 특수 단어 20% 지정 및 프리즈 메카닉스 구현(3초 정지, 연속 출현 방지), ④ CSS transition→@keyframes animation 전환 및 animation-play-state로 프리즈 제어, ⑤ Web Audio API OscillatorNode 기반 효과음 7종 생성 및 음소거 토글, ⑥ fal.ai 배경 이미지 7종 적용(전투 화면 70% 오버레이, 급수 선택 카드 축소 표시)
End goal(최종 목표)스테이지별 난이도 곡선(25초→8초), 특수 단어 프리즈 전략, 7종 효과음, 급수별 배경 이미지가 모두 적용된 완성된 타이핑 디펜스 게임. 모바일 환경에서 소프트 키보드에 의한 낙하 중단 없이 안정적으로 작동
Narrowing(범위 한정)① 기존 게임 코드 수정 금지, ② S1에서 구현된 핵심 게임 로직 변경 금지, ③ 효과음은 외부 오디오 파일 없이 코드만으로 생성

[부록 표4-4] 타자 히어로 2단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
스테이지별 속도 가속급수 내 첫→마지막 스테이지 선형 보간. 1급 25→18초, 2급 25→16초, 3급 25→14초, 4급 23→12초, 5급 23→11초, 6급 23→10초, 7~9급 20→8초
특수 단어 프리즈스테이지 단어의 20%를 특수 단어로 지정(빨간색 테두리). 격퇴 시 화면 전체 3초간 정지: 모든 낙하 단어의 animation-play-state를 paused로 전환. 연속 출현 방지(최소 일반 2개 간격)
CSS @keyframes 전환CSS transition을 @keyframes animation으로 전환. DOM 리렌더와 무관하게 독립 실행하여 모바일 소프트 키보드 열림 시 낙하 중단 방지. 프리즈는 animation-play-state로 제어
효과음7종Web Audio API AudioContext·OscillatorNode로 코드 생성. 격퇴(상승음), 오답(하강음), 콤보(화음), HP 감소(저음), 프리즈(결정화), 클리어(도-미-솔), 실패(솔-미-도). 음소거 토글 버튼
배경 이미지7종fal.ai flux-pro 모델로 급수별 세로형 일러스트 생성. 전투 화면에 반투명 오버레이(70% 불투명도) 적용. 급수 선택 카드에 해금 급수 배경 축소 표시, 미해금 급수 흑백 처리
급수명 게임화1급 '초원의 마을'~7~9급 '전설의 탑' 7종 테마 명칭. 급수 선택 카드와 전투 화면 상단에 표시
자료에 관하여

이 페이지는 학위논문 부록 1 가운데 3.5 한자 타자 게임: 타자 히어로의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
