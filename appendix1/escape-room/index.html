[부록 표13-1] RISEN 프레임워크 기반 방탈출 S1 프롬프트 설계

RISEN 요소 · S1 적용
Role(역할)중국어 교육용 방탈출 게임을 구현하는 React/TypeScript 웹앱 개발 전문가. Supabase 기반 데이터베이스 설계, Cloudinary 미디어 연동, 고사성어 기반 읽기 퍼즐 인터랙션에 정통한 전문가
Instructions (지시)Supabase에 5개 테이블을 생성하고 파일럿 데이터를 삽입한다. /game/room-escape 라우트에 방탈출 게임 본체를 구현한다. 세트 선택, 방 진입 영상 구간 재생, 방 탐색(배경 이미지와 오브젝트 오버레이), 퍼즐 4유형 인터랙션, 글자 획득 애니메이션, 4글자 순서 배열, 클리어 영상, 결과 화면의 전체 게임 흐름을 구현한다. 하트 4개 기반 2단계 힌트 시스템, 타이머, DB 저장, 리더보드를 포함한다
Steps(단계)① Supabase 5개 테이블 생성 및 RLS 정책 설정, ② 파일럿 세트 데이터 삽입, ③ 메인 허브 게임 카드 정보 변경, ④ 세트 선택 화면 구현, ⑤ 방 진입 영상 구간 재생 구현, ⑥ 방 탐색 화면 구현, ⑦ 퍼즐 4유형 인터랙션 구현, ⑧ 하트 4개 및 2단계 힌트 시스템 구현, ⑨ 글자 획득 애니메이션 및 수집 슬롯 구현, ⑩ 4글자 순서 배열 구현, ⑪ 클리어 영상 재생 및 결과 화면 구현, ⑫ 타이머, DB 저장, 리더보드 구현
End goal(최종 목표)파일럿 세트(守株待兔) 1세트가 완전히 플레이 가능한 방탈출 게임. 세트 선택에서 4방 순차 탐색, 4글자 배열, 클리어 영상, 결과 화면까지의 전체 흐름이 작동하는 상태
Narrowing(범위 한정)① 모든 영상과 이미지는 Cloudinary URL로 사전 제공하며 게임 플레이 중 AI API 호출은 0회이다. ② 영상은 세트당 12초 1개로 room_order에 따라 3초씩 구간 재생한다. ③ 기존 게임 코드는 일체 수정하지 않는다

[부록 표13-2] 방탈출 1단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
SQL 테이블 생성room_escape_sets(세트 정보), room_escape_rooms(방 정보), room_escape_puzzles(퍼즐 정보), room_escape_progress(진행 기록), room_escape_leaderboard(리더보드)의 5개 테이블 생성. RLS 설정: 세트·방·퍼즐은 전체 읽기, 진행 기록은 사용자별, 리더보드는 전체 읽기와 사용자별 쓰기

방 탐색 화면bg_image_url을 object-cover로 채우고, objects JSONB 배열의 3개 오브젝트를 position.x, position.y(% 좌표)에 아이콘으로 오버레이. role="clue"는 단서 팝업(중국어와 한국어), role="puzzle"은 퍼즐 팝업
퍼즐4유형selection: choices 4개를 2×2 그리드, value===answer.correct로 판정. matching: left/right 배열을 탭-탭 연결, 4쌍 모두 answer.pairs 일치. password: choices 4개를 1×4 버튼. assembly: pieces 4개를 셔플하여 4칸 슬롯, 순서===answer.correct_order
하트·힌트세트 시작 시 하트 4개. 힌트 사용 시에만 차감(1회=1개). 퍼즐 오답은 차감 없이 무한 재시도. 힌트 2단계: 힌트1 사용 후 힌트2 활성화
게임 흐름세트 선택 → [방N 진입영상 → 탐색 → 퍼즐 → 글자 획득]×4 → 4글자 순서 배열 → 클리어 영상 → 결과 화면(점수와 리더보드). 타이머 0초부터 카운트, 배열 정답 시 정지

[부록 표13-6] 방탈출 3단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
동적 데이터 로딩room_escape_sets에서 전체 조회(set_order ASC). 세트 선택 시 해당 set_id로 rooms(ORDER BY room_order ASC)와 puzzles(room_id 기반)를 동적 조회. 하드코딩된 set_id, room_id, puzzle_id 참조를 모두 제거한다
월드 선택 페이지3개 월드 카드 표시: 초급(初级, difficulty=1), 중급(中级, difficulty=2), 고급(高级, difficulty=3). 각 카드에 해당 난이도 세트 수(DB 동적 카운트)와 클리어 진행도를 표시. 월드 수는 difficulty DISTINCT 조회로 결정하여 하드코딩하지 않는다
스테이지 필터링선택한 난이도(difficulty)에 해당하는 세트만 필터링 표시. 미클리어 세트는 🔒 자물쇠 아이콘, 클리어 세트는 🔓와 성어 4글자와 점수 표시
영상 컨테이너 확장방 진입 영상과 클리어 영상의 컨테이너를 max-w-lg(512px)에서 max-w-3xl(768px)로 확장. aspect-video 적용. 게임 플레이 영역(방 탐색, 퍼즐 팝업)은 기존 max-w-lg 유지
리더보드 로그인 필수게스트 플레이 가능하나 리더보드 기록 저장 안 됨. 게스트가 리더보드 버튼 클릭 시 로그인 안내 표시
