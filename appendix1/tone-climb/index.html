자료 01

[부록 표9-1] RISEN 프레임워크 기반 성조 클라임 S1 프롬프트 설계

RISEN 요소 · 성조 클라임 S1 적용
Role(역할)중국어 교육 게임 설계자이자 React 웹앱 개발 전문가. Supabase 데이터베이스 설계와 음성 녹음 기반 발음 판정 시스템 구현에 정통한 전문가
Instructions (지시)Supabase에 6개 테이블을 생성하고 3개 CSV를 적재한다. 월드 선택, 게임 플레이, 세션 종료 모달의 3화면 웹앱을 구현한다. 수직 스크롤러 구조로 캐릭터를 화면 중앙에 고정하고 배경·나무를 스크롤한다. MediaRecorder API로 마이크 녹음을 구현하되, 발음 판정은 시뮬레이션으로 우선 구현한다. 콤보 시스템과 오답 시 하강을 구현한다
Steps(단계)① Supabase에 6개 테이블 생성 및 CSV 데이터 적재, ② 3화면 구조 웹앱 생성, ③ 수직 스크롤러 구현(캐릭터 고정, 배경·나무 스크롤), ④ MediaRecorder API 마이크 녹음 및 볼륨 분석, ⑤ 시뮬레이션 판정(evaluatePronunciation 함수 격리), ⑥ 등급 구간별 출제·콤보·하강·배지·점수 구현, ⑦ 3성 부호(ˇ) 렌더링을 위한 병음 폰트 설정
End goal(최종 목표)3개 월드로 구성된 수직 스크롤러 성조 발음 게임의 기본 골격. CSS 그라디언트 배경과 이모지 캐릭터, 시뮬레이션 판정으로 작동하는 프로토타입
Narrowing(범위 한정)① 발음 판정은 시뮬레이션만 구현한다(Azure 연동은 S2). ② AI 생성 이미지는 적용하지 않는다. ③ 배경음악은 마이크 녹음 품질 보호를 위해 배제한다

[부록 표9-2] 성조 클라임 1단계 프롬프트 핵심 구현 지시

SQL 테이블 생성world1_yinjie(1,094행), world2_main(7,525행), world3_sandhi(363행)의 3개 학습 데이터 테이블과 user_progress, user_badges, sessions의 3개 사용자 데이터 테이블을 생성한다. 학습 데이터는 CSV 3개를 Lovable에 첨부하여 적재한다

게임 흐름월드 선택(3개 카드, 최고 높이·최고 콤보 표시) → 게임 플레이(HUD + 수직 스크롤러 + 출제 카드 + 마이크 버튼) → 세션 종료 모달(통계 + 다시 도전/월드 선택 버튼)

2단계(S2) 프롬프트

RISEN 프롬프트 설계와 Lovable 입력 프롬프트의 핵심 지시

자료 03

[부록 표9-3] RISEN 프레임워크 기반 성조 클라임 S2 프롬프트 설계

RISEN 요소 · 성조 클라임 S2 적용
Role(역할)중국어 교육 게임 설계자이자 음성 인식 기술 전문가. Azure Pronunciation Assessment REST API를 Supabase Edge Function으로 연동하고, Cloudinary 이미지 기반 수직 스크롤러 UI를 구현할 수 있는 전문가
Instructions (지시)S1의 시뮬레이션 판정을 Azure Pronunciation Assessment 실시간 판정으로 교체한다. Edge Function을 경유하여 WAV → Azure REST API 호출 → AccuracyScore 파싱의 전 과정을 구현한다. 임계값 85점 기준 정오답 판정을 적용한다. Azure Neural TTS로 오답 시 정답 발음을 재생한다. Cloudinary에 업로드된 6장의 AI 생성 이미지를 적용하고 수직 스크롤러 클라이밍 연출을 재구현한다
Steps(단계)① Edge Function evaluate-pronunciation 생성, ② evaluatePronunciation 함수를 Azure 연동으로 교체(임계값 85), ③ Edge Function text-to-speech 생성(Azure Neural TTS), ④ 오답 시 TTS 완료 대기 후 다음 문제, ⑤ Web Audio API 효과음 구현, ⑥ Cloudinary 이미지 6장 적용, ⑦ 수직 스크롤러 5계층 재구현, ⑧ 배경 seamless 루프 설정, ⑨ Cloudinary 변환 파라미터로 이미지 최적화
End goal(최종 목표)Azure Pronunciation Assessment 기반 실시간 성조 판정, Azure Neural TTS 정답 발음 재생, AI 생성 이미지가 적용된 수직 스크롤러 게임의 완성
Narrowing(범위 한정)① 출제 로직(등급 구간 출제)은 S1 그대로 유지한다. ② 출제 카드 UI는 S1 그대로 유지한다. ③ 배지 체계는 S1 그대로 유지한다
자료 04

[부록 표9-4] 성조 클라임 2단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
Azure PA 연동Edge Function evaluate-pronunciation을 생성한다. MediaRecorder API로 녹음한 WAV를 Edge Function에 POST하면, Azure Pronunciation Assessment REST API에 referenceText(한자)와 음성을 전송하고 음절별 AccuracyScore를 반환한다. 임계값 85점 이상이면 정답, 미만이면 오답으로 판정한다
Azure Neural TTSEdge Function text-to-speech를 생성한다. 오답 시 zh-CN-XiaoxiaoNeural 음성으로 정답 발음을 재생하고, 재생 완료까지 대기한 뒤 다음 문제를 출제한다
AI 이미지 적용Cloudinary에 업로드된 6장(판다, 대나무 타일, 월드 카드 3장, 배경)을 적용한다. 수직 스크롤러를 배경·대나무·판다·HUD·조작의 5계층 고정 배치로 재구현한다
배경seamless 루프상반부(밤→노을)와 하반부(낮→새벽) 2장 합성 배경을 높이에 따라 translateY로 스크롤하여 seamless 루프를 구현한다

자료 05

[부록 표9-5] RISEN 프레임워크 기반 성조 클라임 S3 프롬프트 설계

RISEN 요소 · 성조 클라임 S3 적용
Role(역할)중국어 교육 게임 설계자이자 학습 UX 전문가. 가중 랜덤 출제 알고리즘, 성조 변조 교육 설계, 병음 중심 UI 설계에 정통한 전문가
Instructions (지시)등급 구간 기반 출제를 전체 풀 가중 랜덤 출제로 전환한다. 출제 카드를 병음 주인공으로 재설계하고, 월드3에서 원형 병음만 표시한다. 배지 체계를 급수 도달에서 높이 도달로 교체한다. 오답 노트를 병음 중심 레이아웃으로 재설계하고 월드별 필터 탭을 추가한다. 월드 선택 화면을 리디자인하고 모바일 최적화를 적용한다
Steps(단계)① 등급 구간 출제 제거 → 전체 풀 가중 랜덤 출제, ② 어려운 음소(zh/ch/sh/r/ü/j·q·x+u)의 높이별 출현 제한, ③ 출제 카드 병음 주인공 전환, ④ 월드3 실제 발음 표시 제거, ⑤ 배지 7종을 높이 도달 배지로 교체, ⑥ 오답 노트 병음 중심 레이아웃 + 2열 그리드 + 필터 탭, ⑦ 월드 선택 화면 리디자인 + 모바일 최적화, ⑧ 콤보 시각 이펙트 강화
End goal(최종 목표)8,982개 음절·단어 풀에서 가중 랜덤으로 출제하는 완성된 성조 발음 게임. 병음 중심 UI, 높이 도달 배지, 병음 중심 오답 노트가 적용된 최종 완성 상태
Narrowing(범위 한정)① Azure 판정 로직은 S2 그대로 유지한다. ② Cloudinary 이미지 URL은 S2 그대로 유지한다. ③ DB 스키마를 변경하지 않는다
자료 06

[부록 표9-6] 성조 클라임 3단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
가중 랜덤 출제등급 구간 출제를 제거하고 전체 풀에서 가중 랜덤으로 출제한다. 높이 0~14에서는 어려운 음소(zh/ch/sh/r/ü/j·q·x+u) 출현을 20%로 제한하고, 15~29에서는 50%, 30 이상에서는 제한 없이 균등 출제한다
출제 카드UI병음을 주인공(큰 글씨)으로, 한자와 뜻을 보조(작은 글씨)로 전환한다. 월드3에서는 원형 병음만 표시하고 변조된 실제 발음은 표시하지 않는다
배지 체계급수 도달 배지를 높이 도달 배지로 교체한다. 높이 10/20/30/50/100 도달, 콤보 10회, 월드 클리어, 성조 달인 등 10종으로 구성한다
오답 노트병음 중심 레이아웃으로 재설계한다. 2열 그리드, 월드별 필터 탭, TTS 재생 버튼을 구현한다. 세션 메모리로 관리한다
월드 선택 리디자인월드 카드에 최고 높이, 최고 콤보, 도전 횟수를 표시하고 하단에 오답 노트·배지 버튼을 배치한다. 모바일 세로 레이아웃에 최적화한다
자료에 관하여

이 페이지는 학위논문 부록 1 가운데 5.2 성조 발음 게임: 성조 클라임의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
