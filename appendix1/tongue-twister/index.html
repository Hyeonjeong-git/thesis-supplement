RISEN 프롬프트 설계와 Lovable 입력 프롬프트의 핵심 지시

자료 03

[부록 표12-3] RISEN 프레임워크 기반 잰말 대결 S2 프롬프트 설계

RISEN 요소 · 잰말 대결 S2 적용
Role(역할)중국어 발음 교육 게임 설계자이자 iFLYTEK ISE 연동 전문가. 잰말 놀이 기반 발음 유창성 대결 게임을 설계하고 리더보드 시스템을 구현할 수 있는 전문가
Instructions (지시)난이도 선택, 잰말 놀이 목록, 플레이(연습·도전 2단계), 결과 모달, 리더보드의 5화면 웹앱을 구현한다. 연습 모드는 TTS 청취와 녹음 재생 자기 교정으로 ISE 미호출, 도전 모드에서만 iFLYTEK ISE read_sentence를 호출하여 fluency 40%, phone 30%, tone 30% 가중 점수를 산출한다. 배지 8종, Azure Neural TTS 모범 발음 캐싱을 구현한다
Steps(단계)① 난이도 선택 화면 구현(초급·중급·고급 3단계 카드), ② 잰말 놀이 목록 화면 구현(카드 그리드, 점수 표시), ③ 플레이 화면 구현(한자·병음 패널, TTS 재생, 연습·도전 탭, 마이크), ④ 징검다리 점프 pcmRecorder 및 Edge Function(iflytek-ise) 재사용 연동, ⑤ 가중 점수 산출(fluency 40% + phone 30% + tone 30%) 및 결과 모달 구현, ⑥ 리더보드 화면 구현(CSS 포디엄 + 배경 이미지), ⑦ Azure Neural TTS 모범 발음 캐싱, ⑧ 배지 8종 달성 로직, ⑨ Cloudinary 배경 이미지 3장 적용
End goal(최종 목표)109개 잰말 놀이의 연습·도전 2단계 발음 유창성 대결 게임. iFLYTEK ISE read_sentence 기반 fluency 가중 평가와 리더보드 순위 경쟁 시스템
Narrowing(범위 한정)① 징검다리 점프의 Edge Function(iflytek-ise)과 pcmRecorder를 재사용한다. ② check_type은 common으로 고정한다. ③ 연습 모드에서는 ISE API를 호출하지 않는다. ④ 기존 게임 코드를 수정하지 않는다
자료 04

[부록 표12-4] 잰말 대결 2단계 프롬프트 핵심 구현 지시

구현 영역 · 핵심 지시 내용
5화면 구조난이도 선택(초급·중급·고급 3개 카드) → 绕口令 목록(카드 그리드, 최고 점수) → 플레이(한자·병음 패널 + TTS + 연습·도전 탭 + 마이크) → 결과 모달(이번 기록 vs 최고 기록 비교, 세부 점수 3항목 바) → 리더보드(CSS 포디엄 시상대)
연습·도전2단계연습 모드: TTS 청취 + 무제한 녹음·재생 자기 교정, ISE 미호출. 도전 모드: pcmRecorder로 PCM 녹음 → Edge Function(iflytek-ise) → 가중 점수 산출. VAD 자동 종료 비활성화, 사용자 수동 탭 또는 60초 최대 시간 도달 시에만 종료
ISE 재사용징검다리 점프의 pcmRecorder 모듈과 Edge Function(iflytek-ise)을 그대로 import하여 재사용한다. check_type은 common으로 고정한다
가중 점수 산출game_score = fluency_score × 0.4 + phone_score × 0.3 + tone_score × 0.3 (0~5). display_score = game_score × 20 (0~100). integrity_score < 3.0 시 display_score × 0.5 감점
Azure Neural TTS성조 클라임의 Edge Function(text-to-speech)을 재사용한다. 모범 발음 재생 + base64 캐싱. Azure 실패 시 Web Speech API 폴백
리더보드해당 绕口令의 전체 사용자 순위. CSS 포디엄 시상대(1위 금, 2위 은, 3위 동). Cloudinary 대회장 배경 이미지. profiles 테이블에서 닉네임·아바타 이모지 로드
배지8종첫 도전 🎤, 초급 마스터 🌱, 중급 마스터 🌿, 고급 마스터 🔥, 만점 도전 💯(95+), 유창성 달인 🎵(fluency 4.5+), 10개 도전 📜, 전체 도전 👑
배경 이미지3장Cloudinary에 업로드된 초급(공원 야외 무대), 중급(실내 극장 무대), 고급(대회장 무대) 배경을 난이도 선택·플레이·리더보드에 적용한다
자료에 관하여

이 페이지는 학위논문 부록 1 가운데 5.5 유창성 게임: 잰말 대결의 단계별 프롬프트 기록을 옮긴 것이다. 본문에는 이를 하나로 요약한 RISEN 통합 표만 실었다. 부록 1 전체 목록으로 돌아가기

핵심 구현 지시 표는 Lovable에 입력한 프롬프트 가운데 핵심 지시에 해당하는 부분을 정리한 것으로, 프롬프트 전문은 아니다. 제시한 문구는 실제 입력 기록이므로 사후에 수정하지 않았으며, 본문에서 ‘웹앱의 데이터 저장소(Lovable Cloud)’로 표기한 대상이 ‘Supabase’로 나타나는 등 본문 표기와 일치하지 않는 부분이 있다.
