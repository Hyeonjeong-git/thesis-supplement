데이터

스테이지 데이터 구축

최대 매칭 알고리즘으로 문법 요목 예문을 스테이지로 전환

《等级标准》 어휘표에서 구축한 11,050개 확장 사전을 매칭 기준으로 삼았다. 문법 요목 예문에서 완전한 문장 1,358개를 추출하고 대화 표지를 포함한 9개를 제외한 뒤, 나머지 문장에 최대 매칭 알고리즘을 적용하여 단어를 분리하였다. 원문 일치 여부, 확장 사전 등록 여부, 분리 단어 수 2~10개 범위의 세 기준으로 검증한 결과 979개 스테이지가 자동 통과하여 확정되었다.

전환

설계 전환 기록

의뢰 기반 실시간 생성에서 스테이지 사전 생성으로

버블버블은 두 차례의 설계 전환을 거쳤다. 초기 설계는 한자 연금술과 같이 Claude API로 미션 데이터를 실시간 생성하는 의뢰 기반 구조였으나, 응답 품질의 불안정성과 문법 학습 체계와의 연결 부족으로 《等级标准》 문법 요목 예문에 기반한 사전 생성 방식으로 전환하였다. 이어 의뢰 기반 미션 구조를 폐기하고 979개 스테이지를 등급별로 순차 진행하는 구조로 전면 재설계하였다.

자료에 관하여

이 페이지는 학위논문 제3장 3.3에서 다룬 버블버블의 개발 기록 가운데, 지면에서 생략한 프롬프트 입력 기록과 개발 과정의 주요 화면을 수록한 것이다. 화면은 개발 당시의 기록이며 현재의 웹앱과 다를 수 있다.

프롬프트 표와 입력 내용은 실제 입력 기록이므로 문구를 사후에 수정하지 않았다. 표 안의 색상 견본은 열람 편의를 위해 화면에서만 덧붙인 것으로, 원문에는 없다.
