등불 수수께끼灯谜

학위논문 본문에서 생략한 프롬프트 입력 기록과 개발 과정의 주요 화면을 수록한다. 게임 설계와 교육적 근거, RISEN 프롬프트 설계표는 논문 본문에 있다.

S1

1단계 — 데이터베이스와 게임 본체

4개 테이블 생성, 480개 수수께끼 적재, 5개 화면 구현

Lovable Cloud 데이터베이스 구축과 게임 본체를 구현하였다. SQL Editor에서 4개 테이블을 생성하고 480개 수수께끼 CSV를 업로드한 뒤, DB 스키마와 게임 메커니즘, 화면 설계 5개, 디자인 가이드를 포함한 통합 구현 프롬프트를 전달하였다.

수수께끼 풀이 모달초급(1~3급) 사지선다 버튼(choices 필드, 정답 위치 매번 셔플). 중급 이상(4~7~9급) 한자 타이핑 입력(inputMode="text", lang="zh"). trim() 처리, 정확히 1자 일치 판정
3단계 힌트 시스템hint_1: 유형별 풀이 방향 안내. hint_2: 구조 힌트(부수·획수). hint_3: 병음+성조. 순차 활성화, 사용 후 화면 유지
오답 처리1차: 재도전. 2차: 힌트 1 자동 표시+재도전. 3차: 정답 공개+해설 카드+기본 점수 20%
점수 계산등급별 기본 점수(1급 5점~7~9급 50점). 무힌트 ×1.5, 빠른 풀이(15초 ×1.4, 30초 ×1.2), 콤보(3연속 ×1.5, 5연속 ×2, 10연속 ×3)
등불 점등 시각 효과정답 시 어두운 등불→밝은 빨간+글로우 확산(0.8초)+폭죽 이펙트(1.5초). 3차 오답 정답 공개 시 반점등(opacity: 0.5)
화면 구성축제 거리 메인(등급별 카드), 등불 거리(5열 그리드, 자유 선택), 풀이 모달(양피지 배경), 수수께끼 수첩(등급별 아코디언+TTS), 칭호(5단계)

X 버튼 버그 수정

정답을 맞힌 뒤 X 버튼으로 모달을 닫으면 정답 기록이 저장되지 않고 등불도 점등되지 않는 버그이다. 모달이 닫힐 때 현재 상태가 정답 공개 이후인 경우 먼저 정답과 점수를 저장하도록 처리 순서를 변경하여 해결하였다.

자료에 관하여

이 페이지는 학위논문 제3장 3.4에서 다룬 등불 수수께끼의 개발 기록 가운데, 지면에서 생략한 프롬프트 입력 기록과 개발 과정의 주요 화면을 수록한 것이다. 화면은 개발 당시의 기록이며 현재의 웹앱과 다를 수 있다.

프롬프트 표와 입력 내용은 실제 입력 기록이므로 문구를 사후에 수정하지 않았다. 표 안의 색상 견본은 열람 편의를 위해 화면에서만 덧붙인 것으로, 원문에는 없다.
